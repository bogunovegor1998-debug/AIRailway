# plans/ — история проектирования

Здесь лежат рабочие заметки по итерациям проекта (v2.0 → v2.3): архитектурные решения, изменения модели данных, переработка недельного прогноза и UX. Это **исторические внутренние планы**, а не актуальная документация — часть упомянутых в них деталей (конкретные имена выгрузок, промежуточная папка `версии/` с копиями прошлых версий) относилась к рабочему процессу разработки.

Актуальное описание архитектуры, файлов, запуска и переменных окружения — в корневом [README.md](../README.md).

Важно про данные:

- исходные выгрузки (Excel/CSV) и служебная статистика **в репозиторий не входят**;
- данные загружаются локально из папки `DATA_DIR` (по умолчанию `data/`) скриптом `scripts/load_excel.py`, для CSV — через `src/loaders/csv_loader.py`;
- каталог `версии/` с копиями предыдущих версий удалён при подготовке публичной копии.
