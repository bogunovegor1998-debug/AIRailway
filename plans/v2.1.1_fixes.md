# v2.1.1 — Исправления и доработки

## Обнаруженные проблемы

### 1. `.env` не синхронизирован с `.env.example`
- В `.env` отсутствуют: `FRAME_PASS_SECONDS`, `FRAMES_TOTAL`, `TURNSTILES_TOTAL`, `STATION_LAT`, `STATION_LON`, `WEATHER_CITY`, `PASSENGERS_PER_TRAIN_THRESHOLD`
- `config.py` берёт дефолты: TURNSTILE=5, FRAME=10 (вместо нужных FRAME=12, TURNSTILE=5)
- Из-за этого математика в недельном прогнозе расходится

### 2. Погода «нет данных»
- `python-weather` возвращает None — нужна отладка

### 3. «Прогноз на сегодня» — показывает прошлые часы
- В 13:37 показывает «00:00 – 12:00»
- Фильтр `h.hour >= current_hour` должен быть `h.hour > current_hour`

### 4. «Моделирование» — показывает весь день вместо оставшейся части
- Та же проблема с фильтром `>=` vs `>`

### 5. ПТВ: размерность «тыс. пасс» → «пасс»
- В разделе «Пассажиропоток узла за прошедший час» убрать «тыс.»

### 6. Недельный прогноз: формулировки про оборудование
- Для не-зелёных: заменить «Минимально требуется: X рамок» на «при использовании всех рамок и турникетов»
- Для зелёных: добавить «нормальная загрузка при X рамках и Y турникетах» — расчёт минимального оборудования для зелёной зоны

### 7. Пароль на вход в бот
- Новый функционал: бот доступен только по паролю

### Фаза 2: Пароль на вход в бот

**2.1 `src/config.py`**
- Добавить: `BOT_PASSWORD = os.environ.get("BOT_PASSWORD", "")`
- Если пароль не задан — бот открыт для всех (обратная совместимость)

**2.2 `.env`**
- Добавить: `BOT_PASSWORD=` (пустой = без пароля; пользователь впишет свой пароль)

**2.3 `src/bot/handlers.py`**
- Ключ в `user_data`: `AUTH_STATE_KEY = "authenticated"`
- Изменить [`cmd_start()`](src/bot/handlers.py:845): если `BOT_PASSWORD` задан и пользователь не аутентифицирован — запросить пароль
- Изменить [`handle_message()`](src/bot/handlers.py:859): если не аутентифицирован — проверить сообщение на совпадение с паролем
  - Совпало → установить `user_data[AUTH_STATE_KEY] = True`, показать меню
  - Не совпало → сообщение об ошибке, запросить снова
- Если аутентифицирован — обычная обработка команд

**Логика:**
```
/start → BOT_PASSWORD пуст? → да → обычное меню
                              → нет → пользователь аутентифицирован? → да → обычное меню
                                                                     → нет → "Введите пароль:"

любое сообщение → аутентифицирован? → да → обычная обработка
                                   → нет → сообщение == BOT_PASSWORD? → да → аутентифицировать, меню
                                                                      → нет → "Неверный пароль"
```
