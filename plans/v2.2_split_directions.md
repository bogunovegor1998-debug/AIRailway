# v2.2 — Разделение прибытия/отправления, погода на русском, минимум оборудования

## Концептуальное изменение

Текущая архитектура группирует часы по `overall_zone` (худшая из двух зон) и показывает прибытие и отправление вместе. Новая архитектура разделяет потоки полностью: для каждого дня строятся **две независимые** группировки — «отправления» (рамки) и «прибытия» (турникеты).

---

## Фаза 1: Новая функция группировки по направлению

**Файл:** [`src/llm/deepseek.py`](src/llm/deepseek.py:70)

Заменить `_group_hours_by_zone()` на `_group_hours_by_direction(hours, direction)` где `direction` = `"departing"` | `"arriving"`.

```python
def _group_hours_by_direction(hours: list[HourResult], direction: str) -> list[dict]:
```

- Группирует по зоне направления (`.departing_zone` / `.arriving_zone`)
- Возвращает: `[{zone, start_hour, end_hour, min_minutes, max_minutes, reasons, min_equipment}]`
- `min_equipment` считается через `calculate_min_equipment()` но интерпретируется по направлению:
  - Отправление: используется только `min_frames`
  - Прибытие: используется только `min_turnstiles`
- Минимальное значение clamped к **2** (не 0, не 1)
- Удалить старую `_group_hours_by_zone`
